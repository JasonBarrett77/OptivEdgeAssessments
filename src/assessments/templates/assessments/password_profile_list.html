A password profile is an exemption, not a setting. It overrides the global Minimum Password Complexity for the accounts it is applied to, so the question is whether the exemption is weaker than what it replaces — which is why both values are on the row. “Never” is the weakest value on this field, not the strictest, so a profile that never expires weakens a global policy that does, and a global that never expires cannot be weakened by anything.
