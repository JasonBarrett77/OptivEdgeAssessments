Query Help
Security Rule Search
Field Types
source_address_name and destination_address_name search raw tokens, resolved object names, and resolved group names.
source_address and destination_address perform semantic IPv4 matching against effective resolved members.
Semantic Operators
matches: every address in the queried IPv4 value must be matched by the rule.
includes: the queried IPv4 value is included in the effective member set.
exactly: an effective member equals the queried IPv4 value exactly.
intersects: any overlap exists with the queried IPv4 value.
equals: the full effective IPv4 set equals the queried IPv4 value.
Value Rules
Supported semantic values: IPv4 host, CIDR, range, and any.
Dynamic groups and Regions are always skipped for semantic evaluation. EDLs and FQDNs are included once their runtime content has been collected via "Refresh EDL/FQDN Cache" - until then they're skipped too.
A rule with negate-source/negate-destination set matches the effective range excluding its listed addresses. This is computed automatically when every listed address is itself resolvable; if not (e.g. it includes a dynamic group or Region), the rule is skipped for semantic evaluation on that side rather than matched backwards.
Include Any? defaults to No, so any members are ignored unless explicitly included.
Examples
source_address matches 10.0.0.0/8
destination_address intersects 172.16.0.0/16
source_address_name contains corp-group
